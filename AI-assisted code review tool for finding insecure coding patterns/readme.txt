================================================================
 SecuRevealer — AI-Assisted Code Review for Insecure Patterns
================================================================

WHAT IS IT
----------
A web application that scans source code for insecure coding
patterns (SQL injection, XSS, command injection, hardcoded
secrets, weak crypto, SSRF, XXE, path traversal, and 30+ more),
explains each finding like a senior security reviewer, and
produces a beautiful downloadable HTML report.

Zero dependencies. No build step. Runs offline.

QUICK START (standalone exe — no Node.js required)
---------------------------------------------------
   dist\SecuRevealer.exe

Double-click it. A console opens, your browser opens
http://localhost:3000 automatically, and the UI is live.
Close the console (or Ctrl+C) to stop the server.

   Set custom port before launching:   set PORT=3001
   Disable auto-open of the browser:   set SECUREVEALER_NO_OPEN=1

The exe is fully self-contained (Node runtime + UI assets are
embedded) — copy the single file anywhere and run it.

QUICK START (from source, requires Node.js)
-------------------------------------------
   node backend/server.js        (or: npm start)

Then open:  http://localhost:3000

HOW TO USE
----------
1. Drag & drop files or folders onto the drop zone
   (or click to browse, or paste code in the textarea).
2. Hit "Run Security Scan".
3. Review the dashboard: severity rings, risk score, findings
   table, and the code viewer highlighting vulnerable lines.
4. Click "Download HTML Report" for a standalone, shareable,
   styled report file.

CLI SMOKE TEST (no browser needed)
----------------------------------
   node demo/scan-demo.js
   (scans public/demo/* and prints a findings summary,
    plus writes demo/demo-report.html)

WHAT IT DETECTS (highlights)
----------------------------
 CRITICAL : SQL injection via concatenation, command injection,
            hardcoded secrets/keys, eval on user input, XXE,
            unsafe deserialization, path traversal joins
 HIGH     : XSS via innerHTML, weak hashing (MD5/SHA1),
            SSRF via user-controlled URLs, open redirects,
            disabled TLS verification, wildcard CORS
 MEDIUM   : missing rate limiting hints, non-constant-time
            compares, deprecated crypto modes, verbose errors
 LOW      : TODO/FIXME security notes, debug flags left on

"AI-ASSISTED" EXPLAINED
-----------------------
Every finding ships with an AI-style review: root cause,
exploitation scenario, concrete fix snippet, and CWE/OWASP
references — generated by the local advice engine
(backend/analysis/aiadvice.js). No network, no API keys.
Optional real-LLM hook is a listed future item.

REPORT
------
The HTML report is fully self-contained (inline CSS, no CDN,
no JavaScript dependencies) — safe to email or archive and it
renders identically offline.

PROJECT LAYOUT
--------------
   dist/SecuRevealer.exe      standalone Windows build (node24-win-x64)
   backend/server.js          HTTP API + static hosting
   backend/analysis/          scanner, detectors, ast, aiadvice
   backend/report/reporter.js HTML report builder
   public/                    index.html, style.css, app.js
   public/demo/               intentionally vulnerable samples
   demo/scan-demo.js          CLI smoke test
   docs at root: architecture.md, memory.md, state.md,
                 todo.txt, readme.txt

REBUILDING THE EXE
------------------
   npx -y @yao-pkg/pkg . --targets node24-win-x64 --output dist/SecuRevealer.exe

(pkg config lives in package.json: bin, main, pkg.assets —
public/**/* is embedded into the binary.)

SECURITY NOTE
-------------
The demo files under demo/vulnerable/ are INTENTIONALLY
insecure fixtures used to demonstrate detections. Do not copy
them into real projects, and do not "fix" them — the scanner
demo depends on the findings they produce.
