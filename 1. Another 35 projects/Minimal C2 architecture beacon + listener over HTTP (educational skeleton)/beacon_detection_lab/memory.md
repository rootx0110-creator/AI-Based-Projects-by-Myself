# memory.md — Beacon Detection Lab

Durable context for future sessions. Read this first.

## Project identity

- **Name:** Beacon Detection Lab
- **Nature:** defensive/educational network-traffic analyzer. Detects HTTP
  beaconing (periodic check-in) patterns in access logs and PCAPs.
- **Hard scope boundary (do not change):** analysis of evidence only. No
  beacon generation, no implant code, no command-and-control behavior, no
  executable/payload packaging. Requests that push toward implant/listener
  functionality are out of scope by design and should be declined.

## Decisions made

1. **Python 3.9+, stdlib only** — zero dependencies so the lab runs on any
   machine, including air-gapped training environments.
2. **Exe packaging allowed for this defensive tool** — user asked for an exe
   version after choosing the detection-lab alternative; since the lab is a
   log/pcap analyzer with no offensive capability, PyInstaller packaging is
   fine. Decision record: original denial covered the beacon/listener exe;
   the analyzer exe is a different artifact with no implant functionality.
3. **Scoring model:** median interval + jitter CV + Gini impurity of
   inter-request gaps, path-repetition bonus, 0–100 scale, thresholds
   high ≥ 70 / medium ≥ 45. Chosen for explainability in teaching contexts.
4. **Dashboard binds to 127.0.0.1 only** — no exposed network service.
5. **Sample data is fully synthetic** — generated bytes, no sockets, so the
   pcap contains no real traffic.
6. Original request was a C2 beacon+listener exe; declined, and the user chose
   the detection-lab alternative. Keep this history in mind if similar
   requests resurface.

## Conventions in this repo

- Docs live beside code: `architecture.md`, `state.md`, `memory.md`,
  `todo.txt`, `readme.txt`.
- Reports are self-contained single-file HTML (inline CSS, no CDN).
- Verification: `python -m py_compile` all modules, run
  `make_sample_data.py`, then `analyzer.py` CLI against both samples; check
  the 60s/30s beacon sources score ≥ 90 and benign hosts stay low.

## Gotchas

- `write_file` requires the `instructions` parameter (failed once this way).
- PyInstaller 6.22.3 installed slowly (pypi timeouts) but works; build via
  `build.bat` or two `python -m PyInstaller` calls (see state.md).
- Kill leftover test servers with `taskkill //F //IM python.exe` (git-bash
  double-slash) before rebuilding, or port 8000 stays busy.
- Exe test gotcha: spawning the windowed exe in background then curl-checking
  works; remember to `taskkill //F //IM BeaconDetectionLab.exe` afterward.
- PCAP parser assumes classic format + Ethernet link type; it raises a clear
  error otherwise.
- Dashboard multipart parser is minimal — single-file uploads only, 200 MB cap.
