================================================================================
          WebXR Awareness Training Module
================================================================================

Welcome to the WebXR Awareness Training Module! This interactive web application
will help you learn about WebXR - the technology that brings Virtual Reality
and Augmented Reality to the web.

================================================================================
                        GETTING STARTED
================================================================================

1. OPEN THE APPLICATION
   - Open index.html in a modern web browser (Chrome, Edge, Firefox)
   - No installation required! Everything runs in your browser.

2. NAVIGATE THE INTERFACE
   - Sidebar: Access different training modules
   - Dashboard: View your overall progress
   - Lessons: Interactive learning content
   - Quizzes: Test your knowledge
   - Reports: Download your progress summary

3. TRAINING MODULES
   The application includes modules on:
   - WebXR Fundamentals
   - XR Session Management
   - Reference Spaces
   - Input Sources
   - Safety & Best Practices

4. TRACKING YOUR PROGRESS
   - Complete lessons to earn XP
   - Pass quizzes to unlock achievements
   - Your progress is saved automatically

================================================================================
                        FEATURES
================================================================================

* DARK THEME UI - Easy on the eyes with neon accents
* INTERACTIVE LESSONS - Engaging content with code examples
* KNOWLEDGE CHECKS - Quizzes after each module
* PROGRESS TRACKING - Visual dashboard of your learning journey
* REPORT DOWNLOAD - Export your progress as HTML
* AUTO-SAVE - Your progress persists between sessions

================================================================================
                        REPORT DOWNLOAD
================================================================================

To download your training report:

1. Click the "Reports" button in the navigation
2. Select the report type you want:
   - Progress Summary
   - Module Completion Report
   - Full Training Report
3. Click "Generate & Download"
4. The HTML report will download to your device

The report includes:
- Your user ID and session info
- Modules completed
- Quiz scores
- Time spent training
- Achievements earned
- Overall progress percentage

================================================================================
                        TROUBLESHOOTING
================================================================================

PROBLEM: Application doesn't load
SOLUTION: Ensure you're using a modern browser with JavaScript enabled

PROBLEM: Progress not saving
SOLUTION: Check that localStorage is enabled in your browser settings

PROBLEM: Dark theme not displaying
SOLUTION: Refresh the page and ensure CSS loaded properly

================================================================================
                        TECHNICAL INFO
================================================================================

- File: index.html (main application)
- Style: styles.css (dark theme with neon accents)
- Logic: app.js (all JavaScript functionality)
- Data: Stored in browser localStorage

No server required - runs entirely client-side!
