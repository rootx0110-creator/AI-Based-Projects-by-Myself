SKILL ATLAS

Security Skills Atlas

An interactive Three.js portfolio that maps every hands-on project in the workspace into an orbiting 3D galaxy — one glowing node per skill, grouped by discipline on planetary rings.

  • 50 skills across 9 disciplines — offensive security, detection engineering, forensics, incident response, defensive hardening, network tooling, adversary simulation and reporting.
  • Built 100% client-side with WebGL (Three.js), Unreal Bloom post-processing and zero backend.
  • HTML report download produces a self-contained, print-ready portfolio report.

All projects were developed for legal, defensive and lab/authorized use only.
