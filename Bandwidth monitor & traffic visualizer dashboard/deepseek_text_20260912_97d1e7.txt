Build a complete Windows desktop GUI application (.exe) for a "Bandwidth Monitor & 
Traffic Visualizer Dashboard". The application must capture live network traffic, 
display real-time graphs, per-process breakdowns, and historical analytics. It must 
be production-ready, well-architected, and include full documentation files.

═══════════════════════════════════════════════════════════════
PROJECT REQUIREMENTS
═══════════════════════════════════════════════════════════════

TECH STACK (choose ONE and justify):
  - Python 3.11 + PyQt6/PySide6 + pyqtgraph + psutil   →  recommended
  - OR Python + CustomTkinter + matplotlib (lighter)
  - OR Electron + Node.js (systeminformation + Chart.js)
  - OR C# .NET 8 + WPF + LiveCharts2
  - OR Rust + Tauri + sysinfo

CORE FEATURES:
  1. Live Bandwidth Capture
     - Per-interface up/down throughput (bytes/sec)
     - Global aggregate (all interfaces combined)
     - Sample interval: 100ms–1s (user configurable)
     - Works on Windows (psutil) + fallback to WMI/PDH counters
  2. Per-Process Traffic Breakdown
     - Map connections → PID → process name/icon
     - Top-N processes by bandwidth (bar chart / table)
     - Drill-down: per-process connection list (remote IP:port, state)
  3. Real-Time Visualization Dashboard
     - Line graph: download & upload over rolling 60s window
     - Area chart: stacked per-interface
     - Gauge: current speed (Mbps) vs. link capacity
     - Heatmap: hourly traffic (last 24h)
     - Pie/donut: protocol or process distribution
  4. Historical Analytics
     - SQLite storage of samples (aggregate + per-process)
     - Daily / weekly / monthly rollups
     - Top talkers over time range
     - Data usage quota alerts (e.g. 100 GB/month)
  5. Alerts & Notifications
     - Speed threshold alerts (e.g. > 50 Mbps sustained)
     - Quota warnings (80%, 95%, 100%)
     - New-connection alerts for watched processes
     - Toast notification + tray balloon
  6. GUI Features
     - Tabs: Dashboard · Processes · Interfaces · History · Settings
     - Dark/light theme toggle
     - System tray icon with mini-speed tooltip
     - Always-on-top mini widget (floating HUD)
     - Export data to CSV / JSON / PNG (chart snapshots)
  7. Config persistence (JSON in %APPDATA%/NetPulse/)
  8. Single-instance lock
  9. Graceful shutdown (flush DB, close sockets)

NON-FUNCTIONAL:
  - Non-blocking sampling (background thread / asyncio)
  - Ring buffer for live graphs (no unbounded memory growth)
  - DB writes batched every N seconds (avoid disk thrash)
  - Bundle as a single .exe (no console window)
  - Include app icon (.ico)
  - Build script (build.bat / pyinstaller spec)
  - Optional: admin-elevation manifest for full per-process stats

DATABASE SCHEMA (SQLite)
═══════════════════════════════════════════════════════════════

samples(
  id INTEGER PK,
  ts INTEGER,                -- unix ms
  iface TEXT,
  bytes_sent INTEGER,
  bytes_recv INTEGER,
  pkts_sent INTEGER,
  pkts_recv INTEGER
)
CREATE INDEX idx_samples_ts ON samples(ts);
CREATE INDEX idx_samples_iface_ts ON samples(iface, ts);

process_samples(
  id INTEGER PK,
  ts INTEGER,
  pid INTEGER,
  process_name TEXT,
  bytes_sent INTEGER,
  bytes_recv INTEGER
)

rollups(
  bucket_ts INTEGER PK,      -- start of hour/day
  granularity TEXT,          -- 'hour' | 'day' | 'month'
  bytes_sent INTEGER,
  bytes_recv INTEGER,
  peak_down_bps INTEGER,
  peak_up_bps INTEGER
)

quotas(
  id INTEGER PK,
  name TEXT,
  period TEXT,               -- 'daily' | 'monthly'
  limit_bytes INTEGER,
  current_bytes INTEGER,
  last_reset INTEGER
)

═══════════════════════════════════════════════════════════════
SAMPLE RATE STRATEGY
═══════════════════════════════════════════════════════════════

- Interface counters: poll psutil every 500ms (default)
- Per-process: refresh every 2s (expensive)
- Live graph: push to ring buffer every sample, redraw at 10 FPS
- DB writes: batch every 10s (one INSERT per interface)
- Rollups: computed every 5 min for the current hour
