        SOC ALERT TRIAGE DASHBOARD - Severity Scoring & Deduplication
================================================================================

Version: 1.0
Date: September 2026

--------------------------------------------------------------------------------
DESCRIPTION
--------------------------------------------------------------------------------
A professional Security Operations Center (SOC) Alert Triage Dashboard that 
provides intelligent alert management with automated severity scoring and 
deduplication capabilities. Built as a standalone web application that can 
run directly in any modern browser.

--------------------------------------------------------------------------------
FEATURES
--------------------------------------------------------------------------------
  - Real-time alert monitoring dashboard
  - Automated severity scoring (Critical, High, Medium, Low, Info)
  - Intelligent alert deduplication engine
  - Interactive filtering and search
  - Visual analytics with charts and metrics
  - One-click HTML report generation and download
  - Responsive design (desktop, tablet, mobile)
  - Dark theme optimized for SOC environments

--------------------------------------------------------------------------------
QUICK START
--------------------------------------------------------------------------------
  1. Open 'index.html' in any modern web browser (Chrome, Firefox, Edge)
  2. The dashboard loads with sample SOC alert data
  3. Use filters to triage alerts by severity, source, or status
  4. Click on alerts to view details and take action
  5. Click "Export Report" to download a comprehensive HTML report
