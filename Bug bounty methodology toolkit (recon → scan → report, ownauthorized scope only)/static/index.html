Engagement checklist

  • Read the program policy — note prohibited techniques and rate limits.
  • Declare in-scope and out-of-scope assets in the Scope tab exactly as the policy lists them.
  • Sign the attestation only when authorization is genuine.
  • Run passive recon first; escalate to active scanning only if the policy allows it.
  • Save the HTML report — attach it to your submission or triage ticket.
  • Never test assets you do not own or are not listed in the authorized scope.
